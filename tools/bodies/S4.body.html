01 / FORMULA

One bullet = verb + what + how + result

core
[Strong verb] [what you did] by [how / method / tool], [result with a number] (+ context that makes the number meaningful)
WeakStrong
Worked on onboarding improvements for the appLifted onboarding conversion 8% by A/B testing 4 UX hypotheses and shipping the 2 significant winners
Responsible for event logisticsLed a 76-member team to run GES '25 for 2,000+ delegates and 35+ CXO speakers
Did market research on fintechWrote 4 sector reports (AI, fintech, climate-tech, cyber) used in advisory for 20+ HNI portfolios

Number types

% change (conversion +8%), scale (2,000 delegates, 76 people), money (₹ saved/raised), time (500 → 60 experiments, 7 → 3 days), rank (Gold, top 3 of 400 teams), count (20+ portfolios).

Verbs by lane

Consulting: structured, recommended, sized, prioritised. Product: shipped, launched, A/B tested, diagnosed. Analytics: modelled, forecast, automated, built. Finance: valued, benchmarked, analysed. Leadership: led, negotiated, mobilised.

Banned words

"Responsible for", "helped", "worked on", "various", "key", "robust", "leveraged", "synergies", "impactful", "in parallel". If a word adds no information, delete it.

The "so what" test: read a bullet and ask "so what?". If the answer isn't already in the bullet, add it. "Mapped 15 user journeys" → so what? → "...and fixed 10 friction points, raising engagement 12%".
02 / ON CAMPUS

The CDC CV

On campus your CV is generated from your ERP profile in a fixed one-page template. You don't choose fonts or layout, so content and ordering are everything. Unverified points print with the stamp "Self declared by the student, CDC could not verify the relevant documents". Recruiters notice it.

VerifyUpload proof (offer letter, completion certificate, certificate of merit, event letter) for every point well before the season. Chase pending verifications; check what your CDC/department coordinators say is accepted.
OrderWithin each section, put the most relevant entry first for the lane you are applying to; most CDC systems allow several CV versions — make one per lane (consulting, product, analytics/finance).
Character limitsThe template caps line length; your current bullets already run to the edge. Write to ~150 characters and read the generated PDF, not the form.
ConsistencyDates, titles and numbers must match LinkedIn, the off-campus CV and what you say in interviews.
RulesCDC internship undertakings bar reneging on an accepted offer and require you to report offers; read them before applying off-campus too.

05 / OFF CAMPUS

The off-campus CV and applicant-tracking systems

For cold emails, referrals and careers-page applications (S6), keep your own one-page CV in Word or LaTeX (Overleaf). Large companies parse it with applicant-tracking software that extracts text and matches keywords before any human reads it.

Make it parseable

Single column, standard headings (Education, Experience, Projects, Leadership, Skills), real text not images, no tables for layout, PDF exported from Word/LaTeX. Test: copy-paste the PDF into a text editor; if the order scrambles, so will the parser.

Keywords

Mirror the exact words in the job description where they are true ("A/B testing", "SQL", "market sizing", "financial modelling"). Don't paste invisible keywords; recruiters see the parsed text.

Header

Name, phone, email, LinkedIn, GitHub/portfolio (VIKRAM's PRD is a product portfolio piece). No photo, no date of birth, no roll number on the off-campus version.

File nameAryan_Rajak_IITKGP_Product.pdf, not CV_final_v7.pdf.
LengthOne page. Always.
Using AIFine for tightening wording; never let it add numbers or skills you don't have. Recruiters increasingly spot generic AI phrasing ("spearheaded", "leveraged", "drove impactful outcomes").
