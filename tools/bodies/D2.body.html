# function with a default argument and an f-string
def emi(principal, annual_rate, months=12):
    r = annual_rate / 12
    return principal * r * (1 + r) ** months / ((1 + r) ** months - 1)

print(f"EMI on ₹1,00,000 at 14% for 12 months: ₹{emi(100000, 0.14):,.0f}")   # ₹8,979

Data structures

list (ordered, mutable), tuple (immutable), dict (key → value, fast lookup), set (unique items, fast membership). Most interview "Python" questions are solved with a dict or a set.

Classic live questions

Count word frequencies; find duplicates in a list; two-sum with a dict; reverse a string; merge two sorted lists; compute a moving average without pandas; parse a date string.

Habits that score

Name variables by meaning (monthly_spend, not x). Test on a tiny input first. Say the time complexity if asked (a dict lookup is O(1), a nested loop O(n²)).

04 / TIME

Window-style operations and time series

# monthly spend and month-over-month growth
monthly = txns.set_index("txn_date").resample("MS")["amount"].sum()
monthly.pct_change().mul(100).round(1)

# customer total on every row, then rank within city (like SUM() OVER, DENSE_RANK)
df["cust_spend"]   = df.groupby("customer_id")["amount"].transform("sum")
df["rank_in_city"] = df.groupby("city")["cust_spend"].rank(method="dense", ascending=False)

# running total and gap between transactions per card (like LAG)
txns = txns.sort_values(["card_id", "txn_date", "txn_id"])
txns["running_total"]   = txns.groupby("card_id")["amount"].cumsum()
txns["prev_date"]       = txns.groupby("card_id")["txn_date"].shift(1)
txns["days_since_prev"] = (txns["txn_date"] - txns["prev_date"]).dt.days

# 7-day rolling average of daily spend
daily = txns.set_index("txn_date")["amount"].resample("D").sum()
daily.rolling(7).mean()
transform vs agg: agg returns one row per group; transform returns a value for every original row (same length as the input) — that is what you need to add a group total or rank back onto the data.

07 / GOTCHAS

Copy-on-Write and other traps

sub = df[df["amount"] > 10000]
sub["flag"] = True          # pandas 3: changes only sub, never df (old versions warned)

df.loc[df["amount"] > 10000, "flag"] = True    # the right way to change df itself

Chained assignment

df[df.x > 0]["y"] = 1 never changes df in pandas 3. Use one .loc[row_cond, col].

Loops

Avoid iterrows() and row-wise apply on big data; vectorised column maths is 10–100× faster. Use np.where/np.select for conditions.

Integer + NaN

A column of ints with a missing value becomes float. Use nullable "Int64" if it matters.

Beyond pandas: Polars (fast, lazy) and DuckDB (SQL directly on CSV/Parquet files) are increasingly used for large data. Knowing they exist and why is enough for most analyst interviews.
08 / PATTERNS

Three analyses you will be asked for

must
Cohort retention table
act = df.assign(month=df["txn_date"].dt.to_period("M"))[["customer_id", "month"]].drop_duplicates()
act["cohort"] = act.groupby("customer_id")["month"].transform("min")
act["age"]    = (act["month"] - act["cohort"]).apply(lambda x: x.n)     # months since first spend
ret     = act.pivot_table(index="cohort", columns="age", values="customer_id", aggfunc="nunique")
ret_pct = ret.div(ret[0], axis=0).round(2)                              # each row starts at 1.0
RFM segmentation (recency, frequency, monetary)
snap = txns["txn_date"].max() + pd.Timedelta(days=1)
rfm = (df.groupby("customer_id")
         .agg(recency=("txn_date", lambda s: (snap - s.max()).days),
              frequency=("txn_id", "count"),
              monetary=("amount", "sum")))
rfm["R"] = pd.qcut(rfm["recency"], 4, labels=[4, 3, 2, 1]).astype(int)       # recent = high
rfm["F"] = pd.qcut(rfm["frequency"].rank(method="first"), 4, labels=[1, 2, 3, 4]).astype(int)
rfm["M"] = pd.qcut(rfm["monetary"], 4, labels=[1, 2, 3, 4]).astype(int)
rfm["score"] = rfm[["R", "F", "M"]].sum(axis=1)                              # 3–12

Use: target "high M, low R" (big spenders going quiet) with retention offers.

Funnel conversion
funnel = pd.Series({"applied": 10000, "approved": 4200, "card_issued": 3900, "first_spend_30d": 2700})
conv = (funnel / funnel.shift(1)).round(3)     # step conversion
overall = funnel / funnel.iloc[0]              # vs top of funnel

10 / TAKE-HOME

How to win a take-home assignment

core
1. Restate the askOne markdown cell: business question, what decision it informs, assumptions.
2. Data checksGrain, rows, NaN, duplicates, date range, oddities — and what you did about each.
3. Answer firstAn executive summary of 3–5 bullets at the top, each with a number.
4. AnalysisOne section per question: code, one chart, three sentences (what, so what, now what).
5. RecommendSpecific actions, the expected impact, and how you'd measure it (D3: A/B test).
6. Limits + next stepsWhat the data can't tell you and what you'd collect next.
7. HygieneRestart kernel and run all before sending; no hard-coded paths; a short README; 5-slide deck if asked.
